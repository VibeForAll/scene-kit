# 主窗多参考共识

## 结论

- 木框：深暖褐细纹旧木，低光泽。
- 窗套：暖米灰旧石材。
- 玻璃：低饱和深烟灰蓝。
- 结构：三个主竖向分区，中央分区再分成两个窄窗，四行，共 16 格。

## 参考来源

检查了正面两个窗位、左侧、右侧、左前 45 度、右前 45 度和背立面共七个构件裁剪。

## 木框颜色交叉验证

七个视角中深暖色木框像素的采样均值约为 RGB `(63, 54, 43)`，对应 `#3F362B`。各视角样本随背光与白平衡在约 `(44, 39, 32)` 至 `(78, 62, 46)` 之间变化，但 R 通道始终高于 B 通道，确认是暖褐色，不是蓝灰或灰褐。

视觉描述在每个可用视角都识别为深棕色木框。部分二分 VQA 问题同时回答“深棕”和“灰棕”，因此没有用单个问答结果定色，而是以跨视图色相、局部放大和描述共识为准。

## 生成前核对

- 身份一致：七个视角均对应同一类高窄分格窗。
- 轮廓一致：正面比例、侧面厚度、窗台深度可相互解释。
- 结构一致：正面确认中央双窄窗，斜视图确认框料层次连续。
- 材质一致：木框保持暖褐，窗套保持浅暖石色，玻璃保持深烟色。
- 安装关系：背面窗框、墙体接触和窗台连接可解释。

该共识在 v4 材质修正前完成。v4 成品再与同一组多视角裁剪复核。
